# Analytics UI Specification

## Metrics
- Posts scanned
- Matched posts
- Qualified leads
- Approval rate
- Comments/messages attempted
- Successful actions
- Replies
- Consultations
- Customers
- Conversion rate

## Views
- Overview
- Campaign comparison
- Funnel
- Time series
- Source performance
- Export-ready table

All analytics must distinguish discovered, approved, executed and converted states.
