# Lead Inbox UI Specification

## Goal
Provide a fast review surface for prioritized opportunities.

## Row data
- Post content
- Source
- Author
- Lead score
- Intent
- Fit
- Suggested reply
- Status
- Timestamp

## Review actions
- Open source
- View AI reasoning
- Edit suggestion
- Approve
- Reject
- Snooze
- Mark not relevant

## Safety
Approval must be explicit for outbound actions.
