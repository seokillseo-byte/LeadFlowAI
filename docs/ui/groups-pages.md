# Groups & Fanpages UI Specification

## Purpose
Manage supported Meta source targets and permissions.

## Features
- Connected account
- Pages/assets available to the account
- Supported groups/source targets when permitted by the provider
- Permission/capability status
- Last successful sync
- Connection error details
- Enable/disable target per campaign

## Safety
Never ask the user to paste cookies, passwords or session tokens. Show the supported authorization path and provider permission requirements.
