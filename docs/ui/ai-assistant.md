# AI Assistant UI Specification

## Purpose
Help users understand leads and improve suggested responses.

## Panels
- Lead summary
- Intent
- Lead score
- Fit
- Need extraction
- Confidence
- Reasoning summary
- Suggested reply
- Alternative replies
- Edit/Regenerate
- Copy
- Use in approval flow

## Guardrails
AI output must be visibly labeled as a suggestion. The assistant cannot approve or execute outbound actions.
