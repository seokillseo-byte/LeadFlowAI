# Keywords UI Specification

## Purpose
Control matching precision without requiring code changes.

## Features
- Include keywords
- Exclude keywords
- Keyword groups
- Exact/phrase/contains matching
- Case normalization
- Vietnamese diacritic-aware matching
- Enable/disable rule
- Test a sample post
- Preview match reason

## UX
Show which keyword caused a match and which exclusion overrode it. Avoid presenting keyword matching as AI certainty.
